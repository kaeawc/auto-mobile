# Reproducing Bugs

Paste a bug report into an AutoMobile request and include the app, platform,
starting state, steps, expected behavior, and actual behavior. Ask the agent to
reproduce the issue, record what happened, and save a device snapshot if another
person needs to inspect the same state.

> Reproduce this bug in the <app-name> <Android|iOS> app:
>
> <bug report>
>
> Report the exact steps, expected and actual results, device and OS version,
> app version, and whether the issue reproduced consistently.
