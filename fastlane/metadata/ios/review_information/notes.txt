ProtoViewer is a viewer for design prototypes that its user authors. A prototype is a validated, declarative JSON document: it describes layout, theme, motion and saved values, and the renderer's feature set is fixed in this binary. The app does not download, install or execute code that adds or changes its features.

The app works on its own: no other app, account or sign-in is needed. The library is empty on first launch until a prototype is imported.

To try the import flow:
1. Save the sample .automobile-proto file attached to this submission to the Files app, then tap it (or share it to ProtoViewer).
2. Choose ProtoViewer. The prototype is validated and added to the library.
3. Tap it to view it. Use the row menu to Relaunch, Reset or Share.

Network access for imported prototypes is off by default and is switched on only in the library settings.
