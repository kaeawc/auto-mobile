# Classification of every *.integration.test.ts for local pre-push runs.
# Windows CI also reads these tiers: unsafe files share one process;
# everything else runs in safe shards beside it.
# Windows CI runs the tiers concurrently WITHOUT isolated state paths; classify a file unsafe if it can touch a default or shared path.
# Format: path | safe or unsafe | one-line reason naming the deciding construct.
#
# safe   = pure fakes over temp directories, in-memory DBs or loopback ephemeral
#          ports. `bash scripts/prepush-integration-safe.sh` runs exactly these,
#          with every AUTOMOBILE_* state path pointed at one fresh temp dir.
# unsafe = spawns or signals real processes, reaches real host tooling (adb,
#          simctl, xcrun, ffmpeg), uses a real DaemonManager without fake
#          spawner/process-table/signaler, touches default or shared paths
#          (~/.auto-mobile, /tmp/auto-mobile*), unsets isolation env, or needs
#          network or devices. These run only in CI.
#
# Every integration test must be listed, in sorted path order, in the PR that adds
# it (test/scripts/integrationSafeTier.test.ts enforces this). Classify by READING
# the file, never by running it; when in doubt, unsafe.
